# Garren's Website

A personal website showcasing Garren Lee's background and current work.

Garren is in New York City and graduated from Cornell University with a master's in Operations Research and Information Engineering, and from UCLA with a bachelor's degree in Statistics and Data Science. He currently works in IBM Consulting's Data and AI practice.

## Development

This is a minimal static website. Open `index.html` directly in a browser or serve the repository with a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
